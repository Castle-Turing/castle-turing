# Will silent competence atrophy the resident?

*A research question, not deferred implementation. Citations from
memory; **[verify]** marks the unconfirmed.*

**What.** `docs/vision.md` describes an assistant "to whom executive
function itself can be offloaded," and commits to owing only the lowest
comprehension altitude by default. The project asks repeatedly how the
resident stays *informed*. It has never asked whether an agent this
capable causes the resident's own capacities to decay. That assumption
is entirely unstated.

Note the dependency the vision creates for itself: an audit the resident
"can't meaningfully evaluate is oversight in name only." **The design
requires the resident to retain evaluative competence while delegating
away the practice that maintains it.**

**The question.** Does sustained delegation of a cognitive function
degrade the delegator's capacity in it — and, sharper, can someone who
no longer performs a task still competently audit it?

Both directions have real evidence. The deskilling literature says yes
to atrophy, and adds the cruel part: automation leaves the human the
hardest residual task (monitoring) with the least practice. The
transactive-memory tradition says offloading to a trusted partner is
normal, healthy human cognition — which is, after all, what having an
executive assistant is.

**Where the answer likely lives.** Bainbridge, "Ironies of Automation"
(1983) — the founding statement of the trap, and short. Aviation skill
decay: Casner et al. on manual flying retention; the "children of the
magenta" training lecture **[verify]**; the Onnasch/Wickens/Manzey
"lumberjack" meta-analysis (2014), which found higher automation
improves routine performance and worsens failure response **[verify]**.
Cognitive offloading: Risko & Gilbert (*TiCS* 2016); Sparrow, Liu &
Wegner on Google effects (2011, note replication disputes **[verify]**);
GPS use and spatial memory **[verify]**. Counter-frames: Wegner's
transactive memory; Clark & Chalmers's extended mind.

The sharpest sub-question — whether assessment competence survives loss
of production competence — I cannot name a settled literature for.
Finding one is part of the brief **[verify existence]**.

**What would change.** The "lowest altitude by default" default inverts
for exactly the domains the audit depends on: where the resident must
keep exercising judgment, the system owes *practice*, not summaries.
The vision's "doing, not being shown" posture already supports this but
currently gates it on the resident opting in to growth. Aviation's
answer — mandated hand-flying, currency windows — suggests scheduled
unassisted intervals as a design element. If the transactive-memory
frame wins instead, the project can stop worrying and say why, in a
principle.

**Priority: high.** This is the live comprehension-design thread, and it
is the one place where the project's two deepest commitments — the
invisible assistant, and the resident who stays capable — may be in
direct tension.
